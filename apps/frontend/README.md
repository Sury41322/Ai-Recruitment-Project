## Features
- Interactive 3D Avatar Interviewer (`AvatarView.tsx`) with real-time lip sync via TalkingHead.
- Push-to-Talk conversational engine with silence detection and humanized follow-ups (`useGeminiLive.ts`).
- Candidate onboarding form (`Form.tsx`) and real-time evaluation dashboard (`result.tsx`).

## Setup
```bash
bun install
cp .env.example .env
bun dev
```
